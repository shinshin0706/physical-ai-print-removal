# 印刷後の回収と残留物検査

3Dプリンターで印刷した部品を小型アームで回収し、固定カメラでプレートを確認するシミュレーションです。A1とPLAの利用を想定していますが、公開用プリンター形状は独自に作った簡略モデルです。実機で動かすコードではありません。

追加学習により、未使用画像の小片40枚の見逃しは40枚から3枚へ減りました。全体の見逃しは110/280枚から73/280枚、空280枚での不要停止は54枚から11枚になりました。一方、回収動作は81条件中15条件の成功にとどまり、画像検査もプレートに近い色や未学習色に弱いままです。自動で印刷を再開できる状態には達していません。

## 作ったもの

白いSO-101、印刷可能な自作ヘラ、台、シュート、回収箱、固定RGBカメラとArUcoをMuJoCoに配置しました。アームは固定経路で110mm押し、80mm上へ退避します。学習AIがアームを動かす構成ではなく、CNNが残留物検査を担当します。

`inspect_plate.PlateInspector.inspect(rgb, K, distortion)`の入力はRGB画像、カメラ内部パラメータ、歪み係数です。3枚以上のマーカーを認識するとプレート面を512×512へ補正し、画素ごとの残留確率を推定します。確率0.5以上の画素が64個以上なら残留物ありとします。マーカー不足は検査不可として停止します。返す`clear`はプレート検査だけの結果で、回収箱への収容、温度、接着解除、印刷再開の許可を意味しません。

## 比較結果

モデルとしきい値を固定した後に生成した560枚で比較しました。7条件それぞれ空40枚、残留物40枚です。同じ画像から128画素と512画素を作り、全手法に同じ条件を与えています。

| 方法 | 残留物280枚の見逃し | 空280枚の不要停止 | 残留判定の画素数 |
| --- | ---: | ---: | ---: |
| 基準CNN、128画素 | 110 | 54 | 20 |
| 基準CNN、128画素、しきい値調整 | 255 | 24 | 5120 |
| 基準CNN、512画素、面積を維持 | 110 | 50 | 320 |
| 基準CNN、512画素、しきい値調整 | 245 | 33 | 65536 |
| 追加学習CNN、512画素 | 73 | 11 | 64 |
| 色判定、512画素、しきい値調整 | 246 | 26 | 16384 |

しきい値調整は別の検証画像280枚で行い、空画像の不要停止が10%以下になる候補の中で見逃しを最小にしました。512画素の基準CNNは候補内でこの条件を満たせなかったため、不要停止が最も少ない候補を採用しています。影を物体と誤認する手法ではしきい値が大きくなり、見逃しが増えました。色判定を含め、しきい値調整だけで両方の誤りを減らせるわけではありません。

追加学習後の見逃し73枚の内訳は、プレートに近い色40枚、未学習の色30枚、小片3枚です。小片と影に対する追加学習の効果は見られますが、未知色への改善はありません。位置補正できない20枚も評価から除かず、停止として数えています。正解領域が縮小で消えた物体も、有無判定の分母に残しています。

動作評価では質量4・8・20g、プレートとシュートの摩擦0.1・0.3・0.6、押す方向の位置ずれ±15mm、横ずれ±20mmと各0mmを組み合わせました。81条件中17条件で箱へ到達し、接触等の基準も満たした成功は15条件です。摩擦0.1で15/27、0.3と0.6では各0/27でした。全体で固定物との接触による失敗は6条件です。摩擦値は実測値ではなく、結果は現実の成功確率を示しません。

## 学習と評価の分け方

CNNは3層・1,657パラメータです。128画素の合成画像240枚を、180枚の学習用と60枚の重み選択用に分けました。Adam、学習率0.003、120エポック、正例重み40で学習し、非空画像の検証IoUが最大の重みを保存しました。

追加学習では、通常・1.5〜5mmの小片・強い影・低露光の320画像を別seedで生成しました。512画素画像から128画素のパッチを切り出し、605パッチで全層を追加学習、別の145パッチの損失で重みを選択しました。元画像の空・残留物の対を分割の単位とし、同じ対からのパッチが学習側と検証側に跨らないようにしています。追加学習はAdam、学習率0.001、50エポック、正例重み10です。正解マスクは学習・採点・表示だけに使用し、推論には渡していません。

- 基準画像生成seed：24701。最初の90対が学習、残り30対が重み選択。
- しきい値検証seed：28701。7条件×20対、280画像。
- 追加画像生成seed：34701。4条件×40対、320画像。
- パッチ抽出seed：35701。対番号が5の倍数なら重み選択側。
- 基準学習seed：4701。追加学習seed：36701。
- 最終評価seed：31701。7条件×40対、560画像。

開発途中では、見逃しに大きな罰則を付ける選び方が検証画像でほぼ常時停止となり、棄却しました。その段階の試験データと結果は採用せず、結果を閲覧する前に開発用として隔離しました。その後の追加学習としきい値選択を終えてから、seed31701の最終評価を行っています。最終評価の結果を見た再学習はしていません。

## 再現方法

Python 3.13と`uv`を使用します。依存関係は`uv.lock`に固定しています。検証環境はmacOS/Apple Silicon、MuJoCo 3.3.7、PyTorch 2.15.0です。初回だけ依存関係を取得してください。

```bash
uv sync --frozen
uv run python reproduce.py scores
```

同梱の全560件の推定画素数から比較表を再計算するテスト、成功判定、公開形状の資産参照、画像の検査不可処理を確認します。大きな画像データのバイト単位検査1件は、データ生成前はスキップされます。

提供した重みとしきい値を固定したまま、画像生成から最終比較を再実行する場合は次です。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 nice -n 15 uv run python reproduce.py vision
```

動作81条件の再実行と動画生成は次です。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 nice -n 15 uv run python reproduce.py motion
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 nice -n 15 uv run python submission_motion.py --videos
```

学習からやり直す場合は、上の短い再現とは別に、展開し直した作業フォルダで次を実行します。生成データと重みを上書きするため、提出時の重みと結果は元のZIPで保持してください。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 nice -n 15 uv run python reproduce.py full
```

学習・描画には数分以上かかります。処理は直列、PyTorchの計算スレッドは最大2です。Linuxの画面なし環境ではMuJoCoのEGL設定が別途必要な場合があり、この環境では未検証です。PDF・動画の再構成はmacOSのArial Unicodeフォントを使います。

```bash
uv run python build_submission_figures.py
uv run python build_design_review.py
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 nice -n 15 uv run python build_current_demo.py
```

大きな画像NPZと生画像は同梱せず、生成スクリプトとseedを同梱しています。`data/submission/vision/*.json`に画像ごとの寸法・色・raw画像ハッシュ、`model/submission/`に重みと選択条件、`outputs/submission/`に81条件・560画像の結果と推定画素数があります。生成XMLには実行環境の資産パスを設定するため、別の保存先ではXMLのハッシュが変わります。GPU/OS/ライブラリ差を越えた画像の完全一致は検証していません。

`a1_workcell.py`等には以前の探索用の関数も残っています。上記の公開用入口はそのCAD読み込み処理を呼びません。制限付きCADを別途取得する必要はありません。実行する入口は`reproduce.py`と`submission_*.py`です。
